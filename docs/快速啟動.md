# 快速啟動（照順序做）

> 一次只做一步。看到 ✅ 才做下一步。
> 指令都在 **專案資料夾**（`AIPE04_group3`）裡執行。
> 下面的指令是 **Windows PowerShell**。Mac 的指令點開 ▶ Mac 就看得到。

---

## 🟦 第一次才要做

### 1. 裝 4 個軟體

- [ ] Docker Desktop：<https://www.docker.com/products/docker-desktop/>
- [ ] Ollama：<https://ollama.com/download>
- [ ] uv：<https://docs.astral.sh/uv/getting-started/installation/>
- [ ] Git：<https://git-scm.com/downloads>

✅ Docker Desktop 打開後，左下角顯示 **Engine running**。

---

### 2. 下載 AI 模型（約 4GB，要等）

```powershell
ollama pull qwen3:4b-instruct-2507-q4_K_M
```

```powershell
ollama pull bge-m3:567m
```

✅ 打 `ollama list`，兩個名字都在。

---

### 3. 調 Ollama 設定

- [ ] 點右下角羊駝圖示 → **Settings** → **Context length** 調成 **16k**

✅ Settings 顯示 16k。

---

### 4. 打開專案資料夾的終端機

```powershell
cd 你的路徑\AIPE04_group3
```

✅ 提示字元最後是 `AIPE04_group3>`。

---

### 5. 建立 `.env`

```powershell
Copy-Item .env.example .env
```

✅ 資料夾裡多了 `.env`。

---

### 6. 產生兩串金鑰

這行**執行兩次**，會得到兩串不一樣的字，先複製起來：

```powershell
uv run python -c "import secrets; print(secrets.token_urlsafe(48))"
```

✅ 手上有兩串長長的亂碼。

---

### 7. 拿模型版本號

```powershell
(Invoke-RestMethod http://127.0.0.1:11434/api/tags).models | Where-Object name -eq 'bge-m3:567m' | Select-Object -ExpandProperty digest
```

✅ 印出一串 64 個字的英數字，複製起來。

<details><summary>▶ Mac</summary>

```bash
curl -s http://127.0.0.1:11434/api/tags | python3 -c 'import json,sys; print(next(m["digest"] for m in json.load(sys.stdin)["models"] if m["name"] == "bge-m3:567m"))'
```

</details>

---

### 8. 改 `.env`

用記事本或 VS Code 打開 `.env`。
**找到就改，找不到就加在最後**，改成這樣：

```env
SESSION_SECRET_KEY=第6步的第一串
AI_COURSE_GATEWAY_URL=http://host.docker.internal:18763
AI_COURSE_GATEWAY_TOKEN=第6步的第二串
AI_COURSE_EMBEDDING_VERSION=第7步那串
LLM_PROVIDER=local
PRACTICE_FEEDBACK_LLM_PROVIDER=local
QUIZ_GENERATION_LLM_PROVIDER=local
```

存檔。

✅ 這 7 行都有，而且沒有空白的。

---

### 9. 照下面「🟩 每次都要做」做一遍

做完再回來做第 10～12 步。

---

### 10. 匯入假資料（老師和課程）

```powershell
uv run python -m scripts.import_demo_data --refresh-existing --apply --confirm-database aipe04
```

✅ 最後一行有 `"mode": "apply"`。

> `--refresh-existing` 會順便把以前匯入的舊版課程內容更新成最新版（舊版的課程介紹夾著「虛構測試資料」等固定文字，會讓 AI 找課變不準）。

---

### 11. 建立 AI 找課的索引

要先確認 **閘道視窗開著**（下面 C 步驟）。

```powershell
$env:AI_COURSE_GATEWAY_URL = "http://127.0.0.1:18763"; $env:AI_COURSE_GATEWAY_TOKEN = (Select-String -Path .env -Pattern '^AI_COURSE_GATEWAY_TOKEN=(.*)').Matches[0].Groups[1].Value; $env:AI_COURSE_EMBEDDING_VERSION = (Select-String -Path .env -Pattern '^AI_COURSE_EMBEDDING_VERSION=(.*)').Matches[0].Groups[1].Value; uv run python -m scripts.index_course_embeddings --apply --confirm-database aipe04
```

✅ 最後一行 `indexed=` 和 `published=` 的數字一樣。

<details><summary>▶ Mac</summary>

```bash
export AI_COURSE_GATEWAY_URL=http://127.0.0.1:18763 AI_COURSE_GATEWAY_TOKEN="$(grep '^AI_COURSE_GATEWAY_TOKEN=' .env | cut -d= -f2-)" AI_COURSE_EMBEDDING_VERSION="$(grep '^AI_COURSE_EMBEDDING_VERSION=' .env | cut -d= -f2-)"; uv run python -m scripts.index_course_embeddings --apply --confirm-database aipe04
```

</details>

---

### 12. 放入 AI 找課的推薦問題

閘道一樣要開著。這一步會用 AI 找課實際檢索每一題，通過的才會顯示在聊天視窗。

```powershell
$env:AI_COURSE_GATEWAY_URL = "http://127.0.0.1:18763"; $env:AI_COURSE_GATEWAY_TOKEN = (Select-String -Path .env -Pattern '^AI_COURSE_GATEWAY_TOKEN=(.*)').Matches[0].Groups[1].Value; $env:AI_COURSE_EMBEDDING_VERSION = (Select-String -Path .env -Pattern '^AI_COURSE_EMBEDDING_VERSION=(.*)').Matches[0].Groups[1].Value; uv run python -m scripts.chat_starters --apply --confirm-database aipe04
```

✅ 最後一行 `passed=29/30 mode=apply`（有 1 題目前會自動停用，正常）。

<details><summary>▶ Mac</summary>

```bash

```

</details>

🎉 **第一次設定完成。**

## 🟩 每次都要做

### A. 打開兩個 App

- [ ] Docker Desktop（等到 **Engine running**）
- [ ] Ollama（右下角看得到羊駝）

---

### B. 拿最新程式並啟動

```powershell
git pull origin main
```

```powershell
docker compose up --build -d
```

等 1 分鐘，再打：

```powershell
docker compose ps
```

✅ `python-dev-box` 那行有 **(healthy)**。
（還是 `starting` 就再等一下，再打一次。）

---

### C. 開閘道（開一個 **新的** 終端機視窗）

```powershell
cd 你的路徑\AIPE04_group3
```

```powershell
$env:AI_GATEWAY_TOKEN = (Select-String -Path .env -Pattern '^AI_COURSE_GATEWAY_TOKEN=(.*)').Matches[0].Groups[1].Value; $env:AI_GATEWAY_TIMEOUT_SECONDS = "180"; uv run uvicorn scripts.local_ai_gateway:app --host 127.0.0.1 --port 18763 --no-access-log
```

✅ 出現 `Uvicorn running on http://127.0.0.1:18763`。
⚠️ **這個視窗不要關。** 關掉 = AI 停掉。

<details><summary>▶ Mac</summary>

```bash
export AI_GATEWAY_TOKEN="$(grep '^AI_COURSE_GATEWAY_TOKEN=' .env | cut -d= -f2-)" AI_GATEWAY_TIMEOUT_SECONDS=180; uv run uvicorn scripts.local_ai_gateway:app --host 127.0.0.1 --port 18763 --no-access-log
```

</details>

## 🟨 什麼時候要多做

| 情況 | 做什麼 |
|---|---|
| 課程資料有改 | 再做一次第 11、12 步 |
| 資料庫被清空（網站沒有課程） | 再做一次第 10～12 步 |
| 第一次 pull 到 pgvector 版本（2026-11 AI 找課改版） | `docker compose up --build -d` 會自動換成 pgvector 資料庫映像，資料不會消失；接著做一次第 10～12 步 |
| 改了 `.env` | `docker compose up -d --force-recreate backend` |

---

## 🟥 出問題

| 看到 | 做 |
|---|---|
| 網站沒有資料、一直轉圈 | `docker compose up --build -d`，等 healthy |
| 後端一直不是 healthy | `docker compose logs backend --tail 50`，把紅字貼給組員 |
| `No module named 'scripts'` 或找不到 `.env` | 你不在專案資料夾，先 `cd` 進去 |
| `could not connect to ollama server` | 把 Ollama App 打開 |
| AI 出現 `503` | 閘道視窗被關了，重做 C |
| `cp950` 或 `UnicodeDecodeError` | `git pull origin main` 拿最新版 |

> 想知道每一步在做什麼：看 [AI功能啟動說明.md](AI功能啟動說明.md)。
